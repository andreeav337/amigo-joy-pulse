# 🗑️ CÓMO ELIMINAR FOTOS DE CHARMS

## 📂 UBICACIÓN DE LAS FOTOS:
- **Carpeta**: `client/public/charms/`
- Aquí están todas las fotos de charms que hayas subido

## 🔍 VER QUÉ FOTOS TIENES:
1. Ve a la carpeta `client/public/charms/`
2. Ahí verás todas las fotos que has subido
3. Los nombres siguen el formato: `nombre-charm.jpg` (ej: `letra-a.jpg`)

## 🗑️ ELIMINAR FOTOS:

### ✅ MÉTODO 1: Eliminar archivo individual
1. Ve a `client/public/charms/`
2. Busca la foto que quieres eliminar
3. Haz clic derecho → Eliminar
4. ¡Listo! Ahora mostrará el emoji de respaldo

### ✅ MÉTODO 2: Eliminar todas las fotos
1. Ve a `client/public/charms/`
2. Selecciona todas las fotos
3. Eliminar
4. La carpeta queda vacía y todos los charms volverán a mostrar emojis

## 🔄 QUÉ PASA AL ELIMINAR:
- **Si eliminas una foto**: El charm vuelve a mostrar su emoji original
- **No se rompe nada**: El sistema automáticamente usa emojis de respaldo
- **Puedes subir nuevas**: Solo sube otra foto con el mismo nombre

## 📋 NOMBRES DE FOTOS ACTUALES:
(Si existen, los encontrarás con estos nombres)
- `letra-a.jpg`, `letra-b.jpg`, etc.
- `corazon-rojo.jpg`, `estrella-azul.jpg`, etc.
- `gato.jpg`, `perro.jpg`, `corona-dorada.jpg`, etc.

## 💡 CONSEJO:
- Antes de eliminar, asegúrate que el nombre coincida con el ID del charm
- Si solo quieres cambiar una foto, elimina la anterior y sube la nueva con el mismo nombre
